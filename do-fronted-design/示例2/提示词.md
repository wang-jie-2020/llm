# Brutalist 个人作品集首页：高质量提示词

> 直接复制下面整段发送给代码生成助手（如 Claude Code / Cursor / Copilot）。

```text
/frontend-design
你是一名资深前端设计工程师。请为“求职中的全栈开发者”设计并实现一个 **Brutalist 风格个人作品集首页（Single Page）**。

【核心目标】
- 在 30 秒内建立强记忆点并引导联系。
- 整体观感必须“强风格、非模板化、非常见 AI 套版”。

【技术与限制】
- 仅使用：HTML + CSS + Vanilla JavaScript。
- 不允许新增任何依赖（含 UI 库、动画库、字体 CDN、图标库）。
- 可直接本地打开运行。
- 文件输出必须是：
  - src/playground/brutalist-portfolio/index.html
  - src/playground/brutalist-portfolio/styles.css
  - src/playground/brutalist-portfolio/script.js

【视觉风格（必须满足）】
- Brutalist：粗字体、硬边框、高对比、错位网格、极少配色。
- 避免“精致科技风/玻璃拟态/柔和渐变/模板感”。
- 允许不对称和故意冲突感，但要保持信息层级清晰。

【页面信息架构】
1) Hero 区
- 姓名（大标题）
- 职位定位（如 Full-Stack Developer）
- 一句价值主张（短促、有力量）
- 主 CTA（联系我）

2) 项目区（恰好 3 个项目卡）
- 每张卡都包含：Problem / Solution / Result
- Result 必须量化（例如性能提升、转化率、成本节省等）

3) 技能区
- 按类别组织（如 Frontend / Backend / DevOps）
- 强调“可交付能力”，不是关键词堆砌

4) 联系区
- 邮箱 + 至少一个外链位（GitHub/LinkedIn）
- 明确“可联系行动”按钮或链接

【交互要求】
- 滚动 reveal（进入视口触发）
- hover 强反馈（位移/反色/描边变化，反馈明显）
- 键盘可达（Tab 顺序清晰、可见焦点）
- JS 需渐进增强：无 JS 时页面仍可阅读和使用基本链接

【响应式要求】
- 375px（手机）
- 768px（平板）
- 1280px（桌面）
- 在三个断点下都要保证：排版稳定、可读性高、CTA 清晰

【可访问性（WCAG AA）】
- 语义化结构（header/main/section/footer）
- 合理标题层级（h1-h2-h3）
- 颜色对比达到 AA
- 所有交互控件有可见 focus 样式
- 为动态反馈提供 aria-live 或等效可感知方案
- 支持 prefers-reduced-motion
- 提供“跳到主要内容”入口（skip link）

【代码质量要求】
- 结构清晰、命名可读、无冗余代码
- 不写与任务无关的功能
- 不添加注释性废话
- 不输出半成品或 TODO

【输出格式】
请按以下顺序输出完整代码：
1. index.html
2. styles.css
3. script.js
并确保三者可直接运行、相互引用正确。

完成后再附一个“验收清单”，逐条对应以上要求打勾（✅/❌）。
```
