你是「企业级数据可视化总监 + 资深前端UX架构师」，请为【公司名】在【行业】场景下，设计“全球业务导航大屏”（16:9，优先 3840×2160，兼容 1920×1080）。

# 业务目标
1) 一级页面：管理层在 10 秒内看清全球业务健康度与风险分布。
2) 二级页面：点击国家/区域后，快速定位详细运营问题并支持返回。

# 视觉与风格
- 深色指挥舱，克制高级，避免廉价科技风。
- 世界地图为视觉中心（占主视觉约 60%）。
- 强信息层级：同屏不超过 3 个视觉焦点。
- 配色：主背景 #0B1220，强调 #00D1FF / #3B82F6，预警 #F59E0B，严重 #EF4444，成功 #22C55E。

# 一级信息架构（全球总览）
- 顶部：全局 KPI（营收、订单、活跃客户、毛利率、履约率、告警数）+ 全局筛选（时间、区域、业务线、渠道）。
- 中央：世界地图（国家着色 + 流向线 + 热点）。
- 左侧：区域排名、渠道结构、品类占比。
- 右侧：趋势（7/30/90 天）、风险预警、异常事件。
- 底部：时间轴（关键事件）。

# 二级信息架构（国家详情）
- 顶部：面包屑 + 国家 KPI。
- 中央：城市/站点热力、订单漏斗、履约时效。
- 左侧：客户结构。
- 右侧：利润构成、风险清单。
- 底部：国家级事件时间轴。

# 核心交互
- Hover 国家：显示指标卡（核心指标 + 同比/环比 + 风险级别）。
- Click 国家：300–500ms 平滑过渡进入二级详情。
- 联动筛选：时间、区域、业务线、渠道互相联动。
- 支持一键返回一级，并保留筛选状态。

# 可读性与可访问性约束
- 正文字号 >= 16px，关键数字 >= 30px。
- 对比度 >= 4.5:1，色盲友好（状态不只靠颜色表达）。
- 统一单位、币种、时间口径（币种：【USD/CNY/EUR，可配置】）。

# 动效约束
- 仅保留关键动效：数字滚动、流向线呼吸、页面切换过渡。
- 禁止无意义炫技动画，确保决策效率优先。

# 输出内容（按顺序）
1) 信息架构图（一级 + 二级）
2) 页面线框布局（文本框图即可）
3) 图表映射表（模块→图表类型→字段→联动）
4) 设计 Token（颜色/字体/间距/圆角/动效）
5) 关键交互流程（钻取与返回）
6) Mock 数据字段表 + 示例 JSON
7) 前端落地建议（React + ECharts/AntV，组件划分与数据流）

# 实现质量要求
- 输出必须可直接用于开发，不要只给概念。
- 结构清晰、字段完整、命名一致。
- 明确异常态与空数据态展示策略。
