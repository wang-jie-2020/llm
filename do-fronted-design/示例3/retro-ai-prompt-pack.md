# Retro-futuristic AI 落地页提示词包（可复用）

## 1) 一键生成静态预览页（推荐先用）
```text
请为 AI 产品经理生成一个“Retro-futuristic AI 工具落地页”静态单文件（可直接双击打开）。

目标：提升注册意愿；突出 1 个核心卖点 + 2 个差异化能力。
美学：Retro-futuristic（霓虹、网格、玻璃层、微发光），但保持高可读性与清晰信息层级。
技术约束：
- 仅输出 1 个 HTML 文件（内联 CSS/少量原生 JS）
- 不引入任何外部依赖
- 响应式覆盖 375/768/1280
- 可访问性满足 WCAG AA（语义标签、focus-visible、对比度、减少动效支持）
- 性能优先：避免重动画，使用轻量渐变/微交互

页面结构必须包含：
1) Hero
2) Social Proof
3) 功能区（3项）
4) 使用流程（3步）
5) FAQ
6) 最终 CTA

交互要求：轻量视差/渐变动效、按钮微交互、滚动分段节奏。

输出要求：
- 直接给完整 HTML 代码
- 代码可保存为 `retro-ai-preview.html` 后立即浏览
- 文案用中文，语气专业克制，避免夸张营销词
```

## 2) 工程化为 Next.js + CSS Modules
```text
请将已确认的静态落地页工程化到 Next.js（App Router）并使用 CSS Modules，不新增依赖。

输出文件：
- src/app/retro-ai/page.tsx
- src/app/retro-ai/page.module.css

要求：
- 保持现有视觉风格与信息层级
- 保持 375/768/1280 响应式
- 保持 WCAG AA：语义化结构、键盘可访问、focus-visible、合理 aria
- 保持性能优先：减少重动画，支持 prefers-reduced-motion
- 组件结构清晰，但不过度抽象

请先给：
1) 文件改动清单
2) 完整代码
3) 自检结果（结构/可访问性/响应式/性能）
```

## 3) 只优化文案（不改布局）
```text
基于当前落地页，做“提升注册转化”的文案优化，不修改布局结构与样式层级。

目标：
- 强化 1 个核心卖点
- 明确 2 个差异化能力
- 降低理解成本，减少空泛表达

输出格式：
- Hero（标题/副标题/主按钮/次按钮）
- Social Proof
- 功能区 3 项（标题+一句解释）
- 流程 3 步（每步一句）
- FAQ（3-5 条）
- 最终 CTA（标题+按钮）

请额外给出 A/B 两版文案，并说明每版适用场景。
```

## 4) 视觉审查提示词（用于二次迭代）
```text
请作为资深设计评审，审查当前 Retro-futuristic 落地页并给出“最小改动、高收益”的优化建议。

审查维度：
1) 信息层级与首屏理解速度
2) CTA 可见性与行动路径
3) 色彩对比与可读性（WCAG AA）
4) 动效节奏与性能影响
5) 移动端（375）可用性

输出要求：
- 仅给前 8 条最有价值建议（按影响力排序）
- 每条包含：问题 -> 建议 -> 预期收益 -> 实施成本（低/中/高）
- 最后给 1 个“先做清单”（最多 3 项）
```
