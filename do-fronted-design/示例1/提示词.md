# 实验结果可视化叙事单页

为数据分析师做一个“实验结果可视化叙事单页”（Data Story Page）。
目标：让非技术同学 3 分钟看懂结论与证据。
美学：Editorial 杂志风（强留白、非对称排版、黑白主色+1强调色、克制动效）。
技术：React + CSS Modules，不新增依赖，响应式（375/768/1280），可访问性达 WCAG AA。
内容：Hero结论、方法说明、3个关键图表区、反例/局限、最终建议CTA。
实现：输出到 src/pages/ExperimentStory.tsx 与 src/pages/ExperimentStory.module.css，可直接运行。
