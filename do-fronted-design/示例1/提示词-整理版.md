# 提示词（整理版）

你是一名资深前端设计工程师。请生成一个**可双击直接预览的单文件静态网页**（仅 `HTML`，内联 `CSS`，可选少量原生 `JS`），用于展示“实验结果可视化叙事单页（Data Story Page）”。

## 1. 目标与受众
- 目标：让非技术同学在 3 分钟内看懂实验结论、证据与行动建议。
- 受众：业务、运营、产品、管理者。
- 输出倾向：结论先行、证据紧随、可直接决策。

## 2. 设计风格（必须）
- Editorial 杂志风。
- 强留白、非对称排版、清晰层级。
- 黑白/中性色为主 + **单一强调色**（如 `#bb3f22`）。
- 动效克制，仅用于信息进入与按钮反馈。
- 避免通用 AI 模板感（不要彩色渐变堆叠、不要花哨玻璃拟态）。

## 3. 技术约束（必须）
- 输出为 **单个 `.html` 文件**，无需构建工具。
- 不引入第三方依赖（不使用 npm 包，不依赖外部图表库）。
- 图表使用 `SVG + CSS` 或纯 `CSS` 实现。
- 语义化结构：`main/article/header/section` 等。
- 可访问性达到 WCAG AA 基线：
  - 图表需 `role="img"` + `aria-label` 或 `title/desc`
  - 按钮可键盘聚焦，提供 `:focus-visible`
  - 支持 `prefers-reduced-motion`
- 响应式断点：`1280 / 768 / 375`。

## 4. 页面结构（必须包含）
1. Hero 结论区
   - 一句话核心结论（含提升幅度）
   - 3 个关键统计（样本量、置信度、净提升）
2. 方法说明区
   - 简述实验设计与口径控制
3. 关键图表区（3 图）
   - 图1：7日激活率趋势（对照组 vs 实验组）
   - 图2：分人群留存对比（横向条形）
   - 图3：关键指标 uplift 置信区间
4. 反例 / 局限区
   - 说明结论边界与不可外推范围
5. 最终建议 CTA 区
   - 3 条可执行动作 + 2 个行动按钮

## 5. 内容语气
- 专业、克制、可决策。
- 先结论后解释。
- 少空话，避免“可能/大概”等弱判断词。

## 6. 数据与文案（可直接使用，可微调）
- 核心结论：首屏文案改版让新用户 7 日激活率提升 18.4%。
- 样本量：42,816；置信度：95%；净提升：+2.6pp。
- 趋势数据（示例）：
  - 对照组：11.4, 12.1, 12.5, 13.0, 13.6, 13.9, 14.1
  - 实验组：13.2, 14.6, 15.1, 15.5, 16.0, 16.2, 16.7
- 分群对比（示例）：
  - 轻度访问：36.4 → 42.8
  - 移动端新客：31.2 → 39.5
  - 高意向来源：44.1 → 47.4
  - 低速网络：28.9 → 30.3
- 置信区间（示例）：
  - 注册完成率：low 1.8 / mean 3.2 / high 4.5
  - 首单转化率：low 0.6 / mean 1.5 / high 2.7
  - 7日激活率：low 2.9 / mean 4.1 / high 5.3

## 7. 代码质量要求
- 结构清晰，类名语义化。
- 样式变量集中管理（颜色、间距、阴影、字号）。
- 仅保留必要动效。
- 不输出伪代码，不留 TODO。

## 8. 输出格式（严格遵守）
只输出以下两部分，不要额外解释：
1) 完整 `experiment-story-static.html` 代码
2) 一个简短“可视化说明”小节（3-6 行），说明三张图各自传达的业务含义
