# SPC 报警事件查询示例

本文档提供常见查询场景的示例。

---

## 场景一：查询某基地某时间段的总报警数

**用户问法**: "江阴1期上周的SPC报警有多少？"

**查询条件**:
- 基地：江阴1期
- 时间范围：上周（假设为 2024-01-08 至 2024-01-14）

**输出示例**:

```
## SPC 报警事件统计

**查询条件**
- 基地：江阴1期
- 时间范围：2024-01-08 00:00:00 ~ 2024-01-14 23:59:59

**汇总统计**
| 指标 | 数值 |
|------|------|
| 报警总数 | 1,234 |
| 已处理 | 980 |
| 待处理 | 198 |
| 需审核 | 56 |
| 回复率 | 79.4% |

### 按工序统计（TOP 5）
| 工序 | 报警数 | 回复率 |
|------|--------|--------|
| 焊接 | 320 | 85.3% |
| 涂装 | 256 | 78.2% |
| 组装 | 198 | 82.1% |
| 质检 | 145 | 91.0% |
| 包装 | 98 | 75.5% |
```

## 场景二：查询回复率排名（找出处理不及时的产线）

**用户问法**: "哪些产线的SPC报警回复率最低？"

**查询条件**:
- 基地：全部五大基地
- 时间范围：近30天
- 输出：按 replyRate 升序排列

**输出示例**:

```
## SPC 报警回复率排名（低 → 高）

**时间范围**: 2024-01-01 ~ 2024-01-31

### 江阴1期
| 产线 | 报警数 | 回复率 |
|------|--------|--------|
| 产线C | 89 | 62.3% ⚠️ |
| 产线A | 156 | 78.9% |
| 产线B | 203 | 85.2% |

### 江阴2期
| 产线 | 报警数 | 回复率 |
|------|--------|--------|
| 产线D | 67 | 58.2% ⚠️ |
| 产线E | 134 | 81.5% |
...

### ⚠️ 需重点关注
- 江阴1期 产线C：回复率 62.3%，报警数 89
- 江阴2期 产线D：回复率 58.2%，报警数 67
```

## 场景三：查询某工序的 TOP 10 设备报警

**用户问法**: "涂装工序报警最多的设备是哪些？"

**查询条件**:
- 基地：全部五大基地
- 工序：涂装
- 时间范围：近30天

```
**查询条件**

| 2 | 江阴1期 | 涂装机-05 | 38 | 32 | 4 | 84.2% |
| 3 | 江阴2期 | 涂装机-02 | 35 | 30 | 3 | 85.7% |
| 4 | 鄂尔多斯 | 涂装机-01 | 28 | 25 | 2 | 89.3% |
| 5 | 十堰 | 涂装机-03 | 25 | 20 | 3 | 80.0% |
| ... | ... | ... | ... | ... | ... | ... |

### 分析
- 涂装机-01（江阴1期）报警最多，需重点检查设备状态
- TOP 5 设备累计报警 171 次，占涂装工序总报警的 45%
```

## 场景四：查询严重报警

**用户问法**: "上周有哪些严重SPC报警还没处理？"

**查询条件**:
- 基地：全部五大基地
- 时间范围：上周
- 严重程度：严重（IsSevereAlarm=2）
- 状态：待处理（pendingAlarms > 0）

**输出示例**:

```
## 严重 SPC 报警待处理清单

**查询条件**
- 基地：全部五大基地
- 时间范围：2024-01-08 ~ 2024-01-14
- 严重程度：严重问题

### 汇总
| 基地 | 严重报警总数 | 待处理 |
|------|-------------|--------|
| 江阴1期 | 23 | 5 |
| 江阴2期 | 18 | 3 |
| 鄂尔多斯 | 12 | 2 |
| 十堰 | 8 | 1 |
| 沧州 | 5 | 0 |

### ⚠️ 紧急待处理（严重+待处理）
| 基地 | 工序 | 设备 | 报警数 | 待处理数 |
|------|------|------|--------|----------|
| 江阴1期 | 焊接 | 焊机-03 | 8 | 3 |
| 江阴1期 | 组装 | 装配线-02 | 6 | 2 |
| 江阴2期 | 涂装 | 涂装机-01 | 5 | 2 |
| 鄂尔多斯 | 焊接 | 焊机-01 | 4 | 1 |
| 十堰 | 质检 | 检测仪-02 | 3 | 1 |

**总计**: 26 条严重报警中，11 条尚未处理，建议优先跟进
```

## 场景五：多基地对比

**用户问法**: "对比一下五大基地本月SPC报警情况"

**查询条件**:
- 基地：全部五大基地
- 时间范围：本月

**输出示例**:

```
## 五大基地 SPC 报警对比

**时间范围**: 2024-01-01 ~ 2024-01-31

| 基地 | 报警总数 | 已处理 | 待处理 | 回复率 | 排名 |
|------|----------|--------|--------|--------|------|
| 江阴1期 | 1,234 | 980 | 198 | 79.4% | 3 |
| 江阴2期 | 1,089 | 892 | 156 | 81.9% | 2 |
| 鄂尔多斯 | 876 | 745 | 98 | 85.0% | 1 |
| 十堰 | 654 | 510 | 112 | 78.0% | 4 |
| 沧州 | 523 | 445 | 56 | 85.1% | - |

### 分析
- 🏆 **最佳**: 沧州（回复率 85.1%）和鄂尔多斯（85.0%）
- ⚠️ **需改进**: 十堰（78.0%）和江阴1期（79.4%）
- 📊 **最多报警**: 江阴1期（1,234次），建议加强该基地的过程控制
```
