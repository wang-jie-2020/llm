# 社交图排名

用于网络感知外展的规范加权图排名层。

当用户需要时使用它：

- 按介绍价值对现有的相互关系或联系进行排名
- 将温暖路径映射到目标列表
- 测量一阶和二阶连接的桥接值
- 决定哪些目标值得热情介绍而不是直接冷漠外展
- 独立于“领先智能”或“连接优化器”理解图形数学

## 何时使用该独立版本

当用户主要想要排名引擎时选择此技能：

- “我的网络中谁最适合介绍我？”
- “根据谁可以让我找到这些人来对我的互助进行排名”
-“根据此 ICP 绘制我的图表”
- “给我看看桥梁数学”

当用户真正想要时，不要单独使用它：

- 完整的潜在客户生成和出站排序 -> 使用“潜在客户情报”
- 修剪、重新平衡和发展网络 -> 使用 `connections-optimizer`

## 输入

收集或推断：

- 目标人群、公司或 ICP 定义
- 用户当前在 X、LinkedIn 或两者上的图表
- 权衡角色、行业、地理位置和响应能力等优先事项
- 遍历深度和衰减容限

## 核心模型

鉴于：- `T` = 加权目标集
- `M` = 您当前的相互/直接连接
- `d(m, t)` = 从相互`m`到目标`t`的最短跳跃距离
- `w(t)` = 信号评分的目标权重

基础桥牌分数：```text
B(m) = Σ_{t ∈ T} w(t) · λ^(d(m,t) - 1)
```
其中：

- `λ` 是衰减因子，通常为 `0.5`
- 直接路径贡献全部价值
- 每额外一跳贡献减半

二阶展开：```text
B_ext(m) = B(m) + α · Σ_{m' ∈ N(m) \\ M} Σ_{t ∈ T} w(t) · λ^(d(m',t))
```
其中：

- `N(m) \\ M` 是一组相互知道但你不知道的人
- `α` 折扣二阶范围，通常为 `0.3`

响应调整后的最终排名：```text
R(m) = B_ext(m) · (1 + β · engagement(m))
```
其中：

-“参与度（m）”是标准化的响应能力或关系强度
- `β` 是参与奖金，通常为 `0.2`

释义：

- 第 1 层：高“R(m)”和直接桥路径 -> 热情的介绍询问
- 第 2 层：中等“R(m)”和一跳桥接路径 -> 有条件介绍询问
- 第 3 层：低“R(m)”或没有可行的桥梁 -> 直接外展或后续间隙填补

## 评分信号

在图形遍历之前对当前优先级设置重要的目标进行权重：

- 角色或头衔对齐
- 公司或行业契合度
- 当前活动和近期活动
- 地理相关性
- 影响力或影响力
- 反应的可能性

遍历后的权重：

- 进入目标集的加权路径数
- 这些路径的直接性
- 反应能力或之前的互动历史
- 适合制作介绍的上下文

## 工作流程

1. 建立加权目标集。
2. 从 X、LinkedIn 或两者中提取用户图表。
3. 计算直接桥分数。
4. 扩大价值最高的共同基金的二阶候选者。
5. 按“R(m)”排名。
6、退货：
   - 最好的温暖介绍询问
   - 条件桥路径
   - 不存在热路径的图形间隙
