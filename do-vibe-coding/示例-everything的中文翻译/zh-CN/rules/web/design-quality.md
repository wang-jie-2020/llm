# 网页设计质量标准

## 反模板政策

不要发布类似通用模板的 UI。前端输出应该看起来是有意的、固执己见的并且针对产品。

### 禁止模式

- 默认卡片网格，间距均匀且无层次结构
- 带有居中标题、渐变斑点和通用 CTA 的库存英雄部分
- 未修改的库默认值被冒充为完成的设计
- 平面布局，没有分层、深度或运动
- 每个组件的半径、间距和阴影均一致
- 安全的白底灰风格，带有一种装饰强调色
- 仪表板按数字布局，带有侧边栏+卡片+图表，没有观点
- 无故使用默认字体堆栈

### 所需品质

每个有意义的前端界面都应该至少展示其中的四个：

1.通过尺度对比层次清晰
2. 有意安排间距节奏，各处填充不均匀
3. 通过重叠、阴影、表面或运动实现深度或分层
4. 具有个性的版式和真正的配对策略5. 颜色的使用具有语义性，而不仅仅是装饰性的
6. 感觉经过设计的悬停、焦点和活动状态
7. 在适当的情况下打破网格的社论或便当构图
8. 符合视觉方向的纹理、颗粒或氛围
9. 使流程变得清晰而不是分散注意力的动作
10.数据可视化被视为设计系统的一部分，而不是事后的想法

## 编写前端代码之前

1. 选择特定的风格方向。避免模​​糊的默认值，例如“干净的最小”。
2. 有意定义调色板。
3.慎重选择版式。
4. 至少收集一小组真实的参考资料。
5. 在相关的情况下使用 ECC 设计/前端技能。

## 有价值的风格指导

- 社论/杂志
- 新野蛮主义
- 具有真实深度的玻璃形态
- 具有严格对比的深色奢华或轻奢
- 便当布局
- 滚动讲述
- 3D集成
- 瑞士/国际
- 复古未来主义

不要自动默认为深色模式。选择产品真正想要的视觉方向。

## 组件清单

- [ ] 它是否避免看起来像默认的 Tailwind 或 shadcn 模板？
- [ ] 它是否有有意的悬停/焦点/活动状态？- [ ] 是否使用层次结构而不是统一强调？
- [ ] 这在真实的产品屏幕截图中看起来可信吗？
- [ ] 如果它支持两个主题，浅色和深色是否都是故意的？
