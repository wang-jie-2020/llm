# 工作空间表面审计

只读审核技能，用于回答“这个工作空间和机器现在实际上可以做什么，下一步我们应该添加或启用什么？”的问题。

这是 ECC 对设置审核插件的本机答案。它不会修改文件，除非用户明确要求后续实现。

## 何时使用

- 用户说“设置 Claude Code”、“推荐自动化”、“我应该使用哪些插件或 MCP？”或“我缺少什么？”
- 在安装更多技能、挂钩或连接器之前审核机器或存储库
- 将官方市场插件与 ECC 原生覆盖范围进行比较
- 检查“.env”、“.mcp.json”、插件设置或连接的应用程序表面以查找丢失的工作流程层
- 决定功能是否应该是技能、挂钩、代理、MCP 或外部连接器

## 不可协商的规则

- 切勿打印秘密值。仅显示提供程序名称、功能名称、文件路径以及密钥或配置是否存在。
- 当 ECC 可以合理地拥有表面时，更喜欢 ECC 原生工作流程而不是通用的“安装另一个插件”建议。
- 将外部插件视为基准和灵感，而不是权威的产品边界。
- 明确区分三件事：- 现已可用
  - 可用但没有很好地封装在 ECC 中
  - 不可用，需要新的集成

## 审计输入

仅检查回答问题所需的文件和设置：

1. 回购面
   - `package.json`、锁文件、语言标记、框架配置、`README.md`
   - `.mcp.json`、`.lsp.json`、`.claude/settings*.json`、`.codex/*`
   - `AGENTS.md`、`CLAUDE.md`、安装清单、挂钩配置
2.环境表面
   - 活动存储库中的“.env*”文件和明显相邻的 ECC 工作区
   - 仅显示键名称，例如“STRIPE_API_KEY”、“TWILIO_AUTH_TOKEN”、“FAL_KEY”
3. 连接工具表面
   - 安装的插件、启用的连接器、MCP 服务器、LSP 和应用程序集成
4.ECC表面
   - 现有的技能、命令、挂钩、代理和安装模块已满足需求

## 审核流程

### 第 1 阶段：盘点现有内容

产生紧凑的库存：

- 主动线束目标
- 安装的插件和连接的应用程序
- 配置MCP服务器
- 配置LSP服务器
- 键名称隐含的环境支持服务
- 现有的 ECC 技能已经与工作空间相关如果一个表面仅作为基元存在，请将其指出。示例：

- “Stripe 可通过连接的应用程序使用，但 ECC 缺乏计费操作员技能”
- “Google Drive 已连接，但没有 ECC 原生 Google Workspace 操作员工作流程”

### 第 2 阶段：针对官方和已安装表面的基准测试

将工作空间与以下内容进行比较：

- 与设置、审查、文档、设计或工作流程质量重叠的官方 Claude 插件
- Claude 或 Codex 中本地安装的插件
- 用户当前连接的应用程序界面

不要只列出名字。对于每个比较，回答：

1.他们实际上做了什么
2. ECC是否已经有奇偶校验
3. ECC是否只有原语
4. ECC是否完全缺失工作流程

### 第 3 阶段：将差距转变为 ECC 决策

对于每个真实的间隙，推荐正确的 ECC 原生形状：

|间隙类型|首选 ECC 形状 |
|----------|---------------------|
|可重复的操作员工作流程 |技能|
|自动执行或副作用 |钩|
|专门的委派角色 |代理|
|外部工具桥| MCP 服务器或连接器 |
|安装/引导指南 |设置或审核技能 |默认使用面向用户的技能，在需要操作而不是基础设施时编排现有工具。

## 输出格式

按此顺序返回五个部分：

1. **当前表面**
   - 现在已经可用的东西
2. **平价**
   - ECC 已经达到或超过基准
3. **仅限原语的间隙**
   - 工具存在，但 ECC 缺乏干净的操作技能
4. **缺少集成**
   - 功能尚不可用
5. **前 3-5 个下一步行动**
   - 混凝土 ECC 原生添加物，按影响排序

## 推荐规则

- 每个类别最多推荐 1-2 个最高价值的创意。
- 青睐具有明显用户意图和商业价值的技能：
  - 设置审核
  - 计费/客户操作
  - 问题/程序操作
  - Google Workspace 操作
  - 部署/操作控制
- 如果连接器是特定于公司的，则仅当它真正可用或对用户的工作流程明显有用时才推荐它。
- 如果 ECC 已经具有强大的原语，请提出包装器技能，而不是发明一个全新的子系统。

## 良好的结果

- 用户可以立即看到连接的内容、丢失的内容以及 ECC 接下来应该拥有的内容。- 建议足够具体，可以在存储库中实施，无需再次发现。
- 最终答案是围绕工作流程组织的，而不是 API 品牌。
