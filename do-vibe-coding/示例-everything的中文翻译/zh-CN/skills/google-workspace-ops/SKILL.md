# Google Workspace 运营

这项技能适用于将共享文档、电子表格和平台作为工作系统进行操作，而不仅仅是单独编辑一个文件。

## 何时使用

- 用户需要找到文档、表格或幻灯片并就地更新
- 整合存储在 Google Drive 中的计划、跟踪器、注释或客户列表
- 清理或重组共享电子表格
- 导入、修复或重新格式化 Google 幻灯片
- 从文档、表格或幻灯片生成摘要以供决策

## 首选工具表面

使用 Google Drive 作为入口点，然后切换到正确的专家：

- Google Docs 用于文本较多的文档
- 用于表格工作、公式和图表的 Google 表格
- 用于幻灯片、导入、模板迁移和清理的 Google 幻灯片

不要仅根据文件名猜测结构。先检查一下。

## 工作流程

### 1. 找到资产

从云端硬盘搜索界面开始查找：

- 确切的文件
- 兄弟资产
- 可能重复
- 最近修改的版本

如果多个文档看起来相似，请按标题、所有者、修改时间或文件夹进行确认。

### 2.编辑前检查

进行更改之前：

- 总结当前结构
- 识别选项卡、标题或幻灯片数量- 检测任务是局部清理还是结构手术

选择可以安全执行工作的最小工具。

### 3. 精确编辑

- 对于文档：使用索引感知编辑，而不是模糊重写
- 对于工作表：在显式选项卡和范围上操作
- 对于幻灯片：区分内容编辑与视觉清理或模板迁移

如果所请求的工作是视觉或布局敏感的，请通过检查和验证进行迭代，而不是一次巨大的盲目更新。

### 4.保持工作系统清洁

当文件是较大工作流程的一部分时，还会显示：

- 重复的追踪器
- 过时的套牌
- 过时的文档与规范的文档
- 资产是否应存档、合并或重命名

## 输出格式

用途：```text
ASSET
- file name
- type
- why this is the right file

CURRENT STATE
- structure summary
- key problems or blockers

ACTION
- edits made or recommended

FOLLOW-UPS
- archive / merge / duplicate cleanup / next file to update
```
## 好的用例

- “找到有效的规划文档并对其进行浓缩”
- “清理此客户电子表格并显示流失风险行”
-“将此幻灯片导入幻灯片并使其美观”
- “查找当前跟踪器，而不是陈旧的重复项”
